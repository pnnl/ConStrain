G36CoolingOnlyTerminalBoxHeatingAirflowSetpoint
====================================================================

Brief Description
-------------------------------------------------------------------------------
Cooling only terminal box airflow control when the zone state is heating following the guideline 36 recommendations

Index Description
-------------------------------------------------------------------------------
   * Section 5.5.5.3 in ASHRAE Guideline 36-2021

Datapoints Description
-------------------------------------------------------------------------------
   * mode_operation: System operation mode
   * state_zone: Zone state (heating, cooling, or deadband)
   * flow_volumetric_air_cool_max: Maximum cooling airflow setpoint
   * flow_volumetric_air_heat_max: Maximum heating airflow setpoint
   * flow_volumetric_air_setpoint_min: Minimum airflow setpoint during occupied mode
   * flow_volumetric_air_setpoint: Airflow setpoint

Type Verification Description
-------------------------------------------------------------------------------
Procedure-based

Assertions Type
-------------------------------------------------------------------------------
Pass

Assertions Description
-------------------------------------------------------------------------------
   * switch mode_operation

   * case 'occupied'

   *     heating_maximum = flow_volumetric_air_heat_max

   *     minimum = v_min

   * case 'cooldown', 'setup', 'unoccupied'

   *     heating_maximum = 0

   *     minimum = 0

   * case 'warmup', 'setback'

   *     heating_maximum = flow_volumetric_air_cool_max

   *     minimum = 0

   * 

   * if minimum <= flow_volumetric_air_setpoint <= heating_maximum

   *     pass

   * else

   *     fail

   * end
