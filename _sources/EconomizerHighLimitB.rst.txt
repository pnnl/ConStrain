EconomizerHighLimitB
====================================================================

Brief Description
-------------------------------------------------------------------------------
Differential dry bulb economizer high limit

Detailed Description
-------------------------------------------------------------------------------
Check the 90.1-2016 table

Index Description
-------------------------------------------------------------------------------
   * Table 6.5.1.1.3 in 90.1-2016

Datapoints Description
-------------------------------------------------------------------------------
   * temperature_air_outdoor: Outdoor air temperature
   * temperature_air_return: Return air temperature
   * flow_volumetric_air_outdoor_setpoint_min: Minimum outdoor air volume flow setpoint
   * flow_volumetric_air_outdoor: Outdoor air volume flow

Assertions Description
-------------------------------------------------------------------------------
   * (flow_volumetric_air_outdoor > flow_volumetric_air_outdoor_setpoint_min) AND (temperature_air_return < temperature_air_outdoor)

Type Verification Description
-------------------------------------------------------------------------------
Rule-based

Assertions Type
-------------------------------------------------------------------------------
Fail
