Important Usage Notes

  • This front end and its supporting services are currently in BETA and may contain bugs or unstable behavior.
  • AI-agent features are experimental. Generated workflows and verification cases should be treated as starting-point templates, not plug-and-play final products.
  • Output quality is highly sensitive to the context you provide and the selected generative AI model.

IO Requirements (Docker)

  • Put user files under host user_io/. Containers access the same files under /user_io/.
  • Use /user_io/examples/input/... for input references and /user_io/examples/output/<run-name> for output locations.
  • API path checks enforce allowed roots. /user_io is the primary root, while legacy roots like /data are accepted during migration.
  • Example paths: /user_io/examples/input/data/G36_Modelica_Jan.csv, /user_io/examples/input/verification_cases/G36_library_verification_cases.json, /user_io/examples/output/manual-run.
